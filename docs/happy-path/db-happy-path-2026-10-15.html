1. Меню «Загрузить расписание» → «из базы»

В подменю загрузки расписания рядом с «из Google» и «из файла» появился пункт «из базы» — канон из общей БД портала.

2. Выбор мероприятия из базы

Открывается модалка со списком мероприятий. В прод-режиме (timer.zaborov.ru) показываются сегодняшние; здесь — тестовое «ТЕСТ БД 2026-10-15».

3. Состав из БД загружен

Часы собрали duelsList из базы: 8 поединков, ФИО из справочника людей (локальных записей нет), ярлыки опыта считает сервер.

4. Список поединков — ситуации из БД

В выпадающем списке поединков — реальные ситуации из общей БД (№12 «Увидеть лес за деревьями», №69 «Переход на новую бухгалтерскую систему» и т.д.).

5. Выбран поединок — ситуация и участники из БД

При выборе поединка на часы подставляются ситуация, игроки и секунданты из БД; пишется событие раскрытиеСитуации.

6. «Участники и судьи» — ярлыки опыта

Справочник людей с вычисляемыми ярлыками: опытный / новичок / орг / судья ФУБ; ручные радио опыта в режиме БД скрыты (заменены бейджами).

6. Участники — вычисляемые ярлыки опыта

7. Раскладка судей из duel_judges

Таблица «Расписание» — судьи по коллегиям (нанимающиеся / отправляющие / доверяющие) из базы; пустые слоты формы в БД не пишутся.
