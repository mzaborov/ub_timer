# Выжимка по `History.log` и общая статистика проекта ub-timer

*Сгенерировано на основе журнала `History.log` и структуры репозитория (апрель 2026).*

---

## Кратко о продукте

Веб‑приложение для ведения управленческих поединков: таймеры, судьи, жребий, звуки, протокол и экспорт в Excel. Прод: https://timer.zaborov.ru (см. `README.md`).

---

## Выжимка по вехам из `History.log`

Записи в журнале идут **не в хронологическом порядке** (встречаются даты 2025 и 2026); ниже сгруппировано **по темам**, без дублирования «закрытий сессий».

### Архитектура и сопровождение

- **Рефакторинг «Разбиение timer-code»**: логика разнесена по модулям `state`, `core`, `referees`, `schedule`, `toolbar-sound`, `protocol`, `init`; план заархивирован в `docs/Архив/`; в README — структура и чеклист проверки.
- **Версия и деплой**: счётчик в `version.txt`; версия синхронизируется с `index.html`, основным JS и CSS; скрипты в `scripts/` (`deploy.ps1`, `deploy_and_commit.ps1`, `commit_session.ps1`); исключения деплоя через env (`DEPLOY_EXCLUDE_*`); favicon красная локально/тест, чёрная на проде (по hostname).
- **Архивация планов**: выполненные планы из `.cursor/plans/` перенесены в `docs/Архив/`, статусы задач приведены в соответствие.

### Расписание, загрузка файлов, диагностика

- **Диагностика XLSX/JSON**: при ошибках загрузки выводятся адрес ячейки, контекст поединка/игроков, фрагмент строки с пометкой ▼; ошибки JSON тоже показываются на странице.

### Жребий и звуки интро

- **Жребий с музыкой**: треки из `assets/Sound/intro/`, равномерное мигание до конца трека, затем случайный выбор 50/50; ПКМ — выбор трека; повторный ЛКМ — досрочная остановка; список треков в `index.html` (script), на деплое подставляется из `list.json`.
- **Таймер под кубиком** во время музыки жеребьёвки.
- **Синхронное мигание** левой/правой стороны через один вызов API подсветки; на время жеребьёвки `transition: none`.
- **Криптостойкий случайный выбор** через `crypto.getRandomValues()`; кнопка в состоянии «занято» вместо `disabled` для досрочной остановки.

### Часы и поединок

- **Редактирование времени по двойному клику** (при остановленных часах): формат М:СС или секунды, ограничения по длительности поединка.

### Форма «Участники и судьи»

- Вкладки: **Участники** и **Расписание** (раскладка по поединкам; раньше вкладка называлась «Судьи»).
- **Участники (v35):** добавление по **Enter** в поле «ФИО нового участника» (`addParticipantFromModal` в `js/schedule.js`).
- Ручное назначение в таблице «Расписание», автоназначение, контекстное меню — см. `README.md`, раздел «Форма «Участники и судьи»».

### Форма «Поединок завершён»

- Кнопки судей — **полное имя**, фиксированная высота, одна строка с обрезкой и многоточием.
- **Контекстное меню судей**: «Не может на этот поединок», «Отключился со встречи», режим «Поменять местами» с подсветкой и Escape; исключения на поединок не сохраняются; орги не предлагаются как замена.
- **Звуки**: иконки барабанной дроби и аплодисментов; по умолчанию завершение с аплодисментами; Shift+клик — без звука; подсветка дроби при равном счёте и одном непроголосовавшем судье.
- **Тултип «Завершить поединок» (v33–v36):** Bootstrap Tooltip при наведении **под** кнопкой — «По умолчанию — с аплодисментами. Shift+клик — без звука»; `initFinishDuelButtonTooltip` в `js/init.js`, класс `.tooltip-finish-duel` в `css/timer.css`; `aria-label` для клавиатуры и скринридеров.

### Количество судей и голосование

- **RefereeQty** (5/7/9): нормализация к ближайшему из {5, 7, 9}, при ничьей — **вверх** (6→7, 8→9); функция `normalizeRefereeQty` в `state.js`.
- **Таблица «Расписание» ↔ форма голосования (v32):** в меню заголовка колонки — **«5/7/9 судей»** (классика/парный); число кнопок на форме = `RefereeQty`, не число назначенных фамилий; синхронизация при смене qty и при закрытии модалки; исправлен `stop_duel`.
- **«Вернуть голосование»**: восстановление по плотному индексу видимых судей; исправлен сдвиг; планировалось поле `lastCompletedDuelIndex` в «Состояние сессии» и описание в UI.

### Протокол онлайна и восстановление сессии

- **Экспорт протокола в Excel**: листы с игроками, победителем, голосами судей, длительностями раундов (игровое время); имя файла вида «Протокол &lt;расписание&gt;.xlsx».
- **Состояние в localStorage** и лист **«Состояние сессии»** при экспорте; восстановление фазы, времени, раундов, судей; листы «Протокол» и «Раунды»; кнопки сохранения/загрузки одного `.xlsx` с тремя вкладками.
- **Баннер «Восстановить последний онлайн»** при отсутствии загруженного файла; выпадающее скачивание протокола; результаты поединков в `duelsList` при закрытии модалки.
- **Переход к следующему поединку** после завершения: нормализация номера поединка перед `duelChoosed`.

### Мобильная вёрстка

- Скрыта кнопка `hide_referee_hint_grp` на мобилке; уменьшенный шрифт в бублике паузы при низкой высоте; отступы и выравнивание коллегий в `timer-mobile`.
- **Модалка завершения**: zoom, кнопки и футер в ряд, центрирование счёта и бублика; на проде отмечалась опора на v8 с возможностью отката.

## Примечания

- Для точной хронологии одной вехи смотрите **оригинальный** `History.log`: там же указаны время и дата в формате журнала.
- Числовые метрики (строки, коммиты) зависят от момента снятия снимка; при росте проекта имеет смысл пересчитать командами из раздела «Статистика».
