## Read-only расписание для арбитра

- **Источник:** 2026-10-25, онлайн 29.
- **Запрос:** арбитру нужна отдельная страница-таблица с расписанием **только на чтение**.
- **Предлагаемое:** URL вида `/schedule-ro.html?event=<id>`: номер, тип, ситуация, игроки и секунданты, судьи; без элементов редактирования; кнопка «Обновить» и автообновление; мобильный и печатный вид.
- **Доступ:** по ссылке; для опубликованного мероприятия — без org-сессии, для «Подготовки» — по орг-сессии или отдельному токену.
