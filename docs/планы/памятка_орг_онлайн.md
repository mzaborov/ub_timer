# Памятка: что делает собирательный орг для онлайна

**Дата:** 24.10.2025  
**Контекст:** по просьбе Antonsolorev, совместно с OlegShorin.  
**Сохранено:** 2026-08-15. Текст ниже — близко к оригиналу, без пересказа.

**Главный смысл — бэклог автоматизации онлайна:** что собирательный орг ещё делает руками и что может забрать система. Это **не** справочник `РольОрганизатора` и **не** список новых сущностей.

Собирательный орг в каноне — несколько записей `УчастиеВОрганизацииМероприятия` на человека (или на нескольких людей) в рамках одного мероприятия. Маппинг строк на роли — тонкое приложение в конце («кто в титрах / учёте»), не главная таблица.

Канон: [`05_доменная_модель.md`](05_доменная_модель.md) · [`05_доменная_модель.yaml`](05_доменная_модель.yaml) · план [`05_схема_БД_и_портал.plan.md`](05_схема_БД_и_портал.plan.md).

`РольОрганизатора` сейчас **12** значений (исходные 6 + дополнение 2026-08-13). Enum **не расширяем** этим документом. Роли `назначалСудей` и `велПротоколы` **не предлагаем**: назначение судей и протокол уже алгоритмы.

Нумерация шагов: **2** данные; **3–5** портал (просмотр + редактирование; в плане 05 это п.3–4, «новое» — п.5); **6** = бэклог CRM / видео / бот (в плане 05 — тот же пункт «новый функционал»).

## Текст памятки

До онлайна:

- Запускает регистрацию
- Работает со списками участников
- Нагоняет народ (в том числе ищет и уговаривает новичков)
- Назначает пары
- Ведет коммуникацию в чате (подтвердите участие / выберите ситуацию / выберите секунданта и т.д.)
- Помогает участникам по различным вопросам (подобрать секунданта, например)
- Напоминает о мероприятии
- Готовит данные для часов

Во время онлайна:

- Запускает запись
- Запускает гимн
- Говорит вводные слова
- Назначает судей
- Следит за комнатами Zoom
- Закрепляет игроков
- Ведет протоколы
- Показывает часы, нажимает на кнопки
- Включает музыку
- Запускает опрос обратной связи

После онлайна:

- Монтирует видео
- Рассчитывает рейтинги
- Делает таблицу по начислению баллов
- Ведет коммуникацию в чате

## Уже автоматизировано / в каноне как алгоритм

Не роли орга и не новые классы.

| Строка памятки | Что делает система | Не делать |
|----------------|-------------------|-----------|
| Назначает судей | Алгоритм назначения: не судить свой поединок; неактивных не автоназначать; экспресс — только «Отправляющие на переговоры»; слоты формы 5/7/9. Записи `Судья` у `Поединок` — результат алгоритма. | не роль `назначалСудей` |
| Ведет протоколы | Таймер пишет ход боя как `СобытиеПротокола`. | не роль `велПротоколы`; не «орг ведёт бумагу» как отдельная роль |

`показывалЧасы` — роль учёта оператора кнопок, не «ведение протокола». Протокол пишет таймер.

Рейтинг и таблица баллов — уже отчёт / VIEW (шаг 2, витрина `rating.php`); класса `НачислениеБаллов` нет.

## Кандидаты автоматизации

Что орг ещё делает руками → куда это может уйти в продукт.

### Шаг 3–5 (портал)

| Фаза | Строка | Что может забрать система |
|------|--------|---------------------------|
| До | Запускает регистрацию | форма записи уже есть (`РегистрацияНаМероприятие`, статус `Мероприятие`) |
| До | Работает со списками участников | портал: заявки, `Человек` |
| До | Назначает пары | сетка: `Поединок` (игроки, слоты секундант/2-й игрок, ситуация) |
| До | Помогает подобрать секунданта | слот на `Поединок`; помощь в чате — ещё шаг 6 |
| До | Готовит данные для часов | `Поединок`, `Ситуация`, состав `Судья` (шаг 2 / 3–5) |
| Во время | Показывает часы, нажимает на кнопки | уже часы; учёт оператора — `показывалЧасы` |

### Шаг 6 (CRM / бот / видео)

| Фаза | Строка | Кандидат |
|------|--------|----------|
| До | Нагоняет народ (ищет и уговаривает новичков) | CRM |
| До | Ведет коммуникацию в чате (подтвердите / ситуацию / секунданта) | бот (сам чат); выбор ситуации/секунданта — уже поля `Поединок` |
| До | Напоминает о мероприятии | бот |
| Во время | Запускает запись | видео / Zoom |
| Во время | Следит за комнатами Zoom | операционка Zoom |
| Во время | Закрепляет игроков | pin / комнаты Zoom |
| Во время | Запускает опрос обратной связи | CRM |
| После | Монтирует видео | видео (артефакт — `Видео`, без статуса обработки) |
| После | Ведет коммуникацию в чате | бот |

### Не берём в продукт

Гимн, музыка, вводные слова — оргпроцесс ведущего, не схема и не бэклог автоматизации.

## Приложение: учёт ролей (титры)

Не справочник «какие роли добавить». Enum из 12 значений не меняем. Ниже — кто может стоять в титрах / `УчастиеВОрганизацииМероприятия`, если строка памятки ещё живая руками.

| Строка (ещё не алгоритм) | Учёт (`РольОрганизатора`) |
|--------------------------|---------------------------|
| Запускает регистрацию | `планированиеМероприятия` |
| Списки участников, пары, помощь с секундантом | `подготовкаУчастников` |
| Нагоняет народ | `работаСНовичками` |
| Готовит данные для часов | `подготовкаМатериалов`, `обновлениеДанных` |
| Запускает запись | `велЗапись` |
| Zoom / закрепляет игроков | `настраивалКомнатыZoom` |
| Показывает часы, кнопки | `показывалЧасы` (оператор, не протокол) |
| Монтаж | `обработкаВидео` |
| Рейтинг / таблица баллов | `подведениеИтогов`, `обновлениеДанных` |

Не предлагаем: `назначалСудей`, `велПротоколы`. Отдельную роль `назначалПары` тоже не плодим (сетка — сущность `Поединок` + `подготовкаУчастников`).
