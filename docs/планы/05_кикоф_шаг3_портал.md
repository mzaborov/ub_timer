## 4. Что уже есть на проде (экраны просмотра)

В корне репо **три** публичные страницы. Других `.html` / `.php` витрин нет. Это входная точка шага 3: что уже можно смотреть, чего ещё нет.

### 4.1. Часы — https://timer.zaborov.ru/ (`index.html`)

Операционный экран **проведения** поединка, не портал канона из MySQL.

- Главный экран: часы двух сторон, роли, текст ситуации, выбор поединка после загрузки расписания
- Меню «Поединки в сообществе»: ссылки на банк ситуаций и «Количество баллов»
- Загрузка расписания (Google последний / файл / выбор онлайна)
- Модалки runtime: пауза; завершение и голоса судей; выбор онлайна из Google; «Участники и судьи» (вкладки «Участники» / «Расписание») — состав текущего онлайна, не справочник `Человек` из БД

**Не трогать** фронт таймера на этом шаге, если пользователь явно не попросил.

### 4.2. Банк ситуаций — `situations-bank.html`

Просмотр банка (не из MySQL):

- экран **списка** (код, тип, поиск)
- экран **карточки** (описание, роли, «поделиться»)

Источник: published CSV Google (`gid=94326902`), кэш в `sessionStorage`. Не читать `situations` из MySQL, пока пользователь не подтвердит смену источника.

### 4.3. Количество баллов — `rating.php`

Единственная витрина из MySQL на проде. Одна таблица: место, ФИО, баллы, турниры, победы, поражения, победы/поражения секунданта, судил, голоса. Поиск, сортировка по баллам / ФИО, подсказки по формуле и списку фактов. Отдельной карточки человека **нет**.

Формула (канон Google / код `rating.php`):

`турнир×10 + победа×5 + поражение×3 + сек.победа×4 + сек.поражение×2 + судил×1 + голоса×0.3`

Правила, уже заложенные в код и дамп:

- **Турнир** в формуле = мероприятие с `тип = турнир`. В каноне это **только УБ Лидер**. Полярный экспресс — **региональный мини-офлайн**, не турнир (×10 не давать).
- ×10 за **каждый бой** на турнире, если человек **игрок или секундант** (не судья). Не один раз за встречу.
- Гости ФУБ без членства в «Стрим поединки я-ИТ-ы» в таблицу не входят (Шилова в обоих кругах — видна).
- Ничья / нет голосов — без победы и поражения.

**Не переписывать `rating.php`** в шаге 3 без явной просьбы. Выверка расхождений с Google — **не эта задача** (см. §6).

## 5. Что сделать на шаге 3

Сначала обсудить с пользователем, потом код. Предлагаемые **первые шаги** (не реализовывать в том же ходе, что это предложение):

2. **Список мероприятий + карточка** — read-only из MySQL: название, тип, даты, статус, арбитр; на карточке — поединки (состав `*Id`, ситуация-подпись, судьи/голоса), видео, орги. Ярлык `Мероприятие.ярлык` — URL, если задан, иначе id.

Стек страниц: тонкий PHP 5.2 + `mysql_*` + простой HTML/CSS в том же стиле, что `rating.php` / банк (не тащить SPA). Конфиг БД — тот же `db.inc.php` вне www.
