# UB Timer — нарезка видео (native desktop)

Нативное Windows-приложение вместо браузерной формы: внешний `mpv.exe` в окне Qt, индекс I-кадров,
нарезка ffmpeg. Видео берётся из API портала по токену и кэшируется локально; после
загрузки seek идёт по локальному файлу (горячие страницы держит кэш ОС), без
передекодирования всей записи браузером.

## Что умеет

- Список мероприятий и поединков из API портала (`/api/videocut.php`).
- Помнит последнюю сессию: видео, мероприятие/JSON, сдвиг, выбранный поединок и все границы.
- Автоматические границы по протоколу (`recordingStartMs`, `protoStartMs/EndMs`).
- Автокалибровка старта записи по последнему решению и длительности видео; кнопка «Автостарт».
- Горячие клавиши: Space — play/pause, ←/→ — ±1 с (Shift — ±5 с), [ и ] — шаг по I-кадрам, Ctrl+O — видео, Ctrl+J — JSON.
- Просмотр mpv с мгновенным seek, кнопки ±1/5/15/30/60 с.
- Шаг границы по реальным I-кадрам MP4 (`stss`/`stts`/`ctts`).
- Правка начала/конца, глобальный сдвиг, включение/исключение поединков.
- Превью первого/последнего кадра обновляются автоматически при сдвиге границ.
- Нарезка выбранных поединков в MP4 (H.264/AAC) с именами по шаблону.
- «Умная нарезка» (по умолчанию): точное начало без перекодирования всего фрагмента —
  короткий головной GOP кодируется, остальное копируется потоком; снятый флажок включает
  полное перекодирование для абсолютной точности.
- «Залить видео…»: создаёт папку встречи в Google Drive, загружает полную запись и
  нарезку, открывает файлы по ссылке, привязывает ссылки к поединкам на портале,
  делает скриншот страницы результатов и отправляет сообщение в Telegram.
- Галочка «Удалить локальные нарезки и исходник после заливки» (по умолчанию включена):
  после успешной отправки приложение сверяет размеры всех файлов в Google Drive и
  только затем отправляет локальные файлы в корзину Windows.
- Резервный режим без API: JSON разметки из веб-формы + локальный видеофайл.

## Установка

```powershell
py -3.12 -m pip install -r requirements.txt
```

Нужен `mpv.exe` (MPV Player). Приложение ищет его в `C:\Program Files\MPV Player`,
в `PATH`, рядом с `main.py` и по пути `UB_MPV_EXE`.

Нужны `ffmpeg`/`ffprobe` в `PATH` (или укажите полные пути в настройках).
Проверено: Python 3.12, PySide6 6.12, mpv 0.41, ffmpeg 8.0.

## Запуск

Двойным щелчком `run.bat` или командой:

```powershell
py -3.12 main.py
```

При первом запуске откройте «Настройки» и укажите:

- адрес портала (по умолчанию `https://ciocdo-org-skills.zaborov.ru`);
- токен доступа (сейчас API принимает пароль org-раздела, если отдельный
  `$videocut_api_token` не задан в `db.inc.php`); если токена нет в настройках,
  приложение берёт `PORTAL_ORG_PASSWORD` из локального `kvault` (сессия должна быть
  разблокирована) или из env при запуске через `kvault run`;
- путь к `mpv.exe`, если он не найден автоматически;
- папку кэша и папку результатов.

Порядок получения токена: `UB_VIDEOCUT_TOKEN`, затем `PORTAL_ORG_PASSWORD` из env
(при запуске через `kvault run`), затем токен из `config.json`; если там пусто —
`kvault get PORTAL_ORG_PASSWORD`. Если токен взят из kvault, в файл он не записывается,
пока вы не сохраните настройки.

## API

`GET /api/videocut.php?action=events` — список мероприятий.

`GET /api/videocut.php?action=event&id=55` — событие, поединки, времена протокола,
ссылка на запись дня (`media.mediaUrl`).

`POST /api/videocut.php` с JSON `{"action":"publish","kind":"duel|day",...}` —
привязать ссылку Drive к поединку или полной записи.

Заголовок: `Authorization: Bearer <token>`.

## Кэш и «память»

Видео один раз скачивается в `%LOCALAPPDATA%\ub-timer-videocut\cache` (докачка через
HTTP Range, файл `.part`). Дальше mpv, парсер I-кадров и ffmpeg читают один и тот же
локальный файл; ОС держит горячие страницы в памяти, поэтому переходы по I-кадрам
идут за десятки миллисекунд. Полная загрузка в RAM не делается, чтобы не упираться
в гигабайты на двух-трёхчасовых записях.

Состояние работы сохраняется в `%APPDATA%\ub-timer-videocut\session.json` (видео,
источник, сдвиг, выбранный поединок, границы и галочки). При следующем запуске
приложение открывает последнее видео и возвращает правки; файл пишется с задержкой
0,4 с после изменений и сразу при закрытии окна.

## Ограничения MVP

- Публикация нарезанных файлов в Drive/`videos` пока не автоматизирована: файлы
  складываются в папку результатов.
- Нет покадрового (не I-frame) шага: границы двигаются по ключевым кадрам.
- Таймлайн без зума; для длинных записей удобнее список поединков.
