## Why

Кнопка «Сгенерировать пары из заявок» в рабочем месте орги ([portal/inc/org_events.php](../../../portal/inc/org_events.php)) сейчас — заглушка «Пока не умеем — скоро». Орг вручную собирает пары игроков на онлайн-мероприятиях, что медленно и не гарантирует бизнес-правила (приоритет новичков, запрет «новичок против новичка», разнообразие соперников, подбор по силе). Правила уже зафиксированы в [docs/планы/07_пары_из_заявок.md](../../../docs/планы/07_пары_из_заявок.md); не хватает реализации.

## What Changes

- Кнопка «Сгенерировать пары из заявок» генерирует пары игроков **и сразу сохраняет** сетку; повторное нажатие даёт другой вариант.
- Генератор заполняет **только игроков** (`player1_id`, `player2_id`) слотов типов **классика** и **экспресс**. Парный тип и секунданты — вручную, генератор их не трогает.
- Бизнес-правила генерации:
  - приоритет Группы A (участники с менее 3 играми) по воронке «без игр → 1 → 2», без перескоков; не судивших — играть последними внутри Группы A;
  - жёсткий запрет: два новичка (0 игр) друг против друга;
  - разнообразие соперников (штраф за недавнюю пару);
  - подбор близких по силе — **Elo**;
  - для Группы B — давно не игравшие + разнообразие + сила.
- Метрика силы — **Elo** по истории поединков; кэш в новой таблице `person_elo`; пересчёт при импорте протокола + разовый бэкфилл.
- Модель заявки делится на **пожелания участника** (мягкие) и **пометки орга** (жёсткие запреты, видны только оргу):
  - пожелания участника: роли (играть/судить/секундировать), тип поединка (как сейчас, одиночный), комментарий;
  - пометки орга: «не играть», «запрещённые типы».
- Запрет орга на тип — вето (человек не попадает в слот такого типа); пожелание участника по типу — мягкое предпочтение.
- Роль «судить» учитывается **слабым фактором** приоритета игры.
- Выбор секунданта вне заявок — **авто-добавление** его в заявку мероприятия.
- Типы поединков задаёт орг по слотам (существующее `duels.duel_type`) — генератор их не меняет.

## Capabilities

### New Capabilities
- `org-pair-generation`: генерация пар игроков из заявок мероприятия по бизнес-правилам (приоритет воронки, вето «новичок × новичок», разнообразие, Elo), пожелания участника и запреты орга, авто-добавление секунданта в заявку.

## Impact

- `portal/inc/org_events.php` — новый обработчик `org_gen_pairs`, правки карточки «Слоты», combo секунданта (авто-добавление в заявку), поля заявки (пометки орга).
- `portal/js/org-events.js` — обработчик кнопки (вместо заглушки).
- БД: новая таблица-кэш `person_elo`; новые поля пометок орга в `meeting_registrations`.
- Импорт протокола — пересчёт Elo; разовый бэкфилл по `duels` + голосам судей.
- Документация: [docs/планы/07_пары_из_заявок.md](../../../docs/планы/07_пары_из_заявок.md).
- Не затрагивает таймер, автоназначение судей и протокол.

## Non-goals

- Не подбираем секундантов (ищут сами игроки) и не генерируем парный тип.
- Не назначаем судей (отдельный алгоритм) и не трогаем протокол/таймер.
- Не проставляем ситуации (участники выбирают сами) и не меняем типы слотов.
- Не меняем воронку/цель стрима (3 игры) и не расширяем `РольОрганизатора`.
