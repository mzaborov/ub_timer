## Why

Офлайн-мероприятиям «Управленческих поединков» нужен печатный буклет с ситуациями: участники и судьи получают раздатку с текстами ситуаций (как в примере Саши — `Ситуации классические` / `Экспресс ситуации`, с блоками «РОЛИ И ИНТЕРЕСЫ»). Сейчас ситуации живут только в банке портала ([portal/inc/org_situations.php](../../../portal/inc/org_situations.php)); организатор вручную собирает буклет в Word, что медленно и расходится с данными банка. Нужна генерация буклета из портала по конкретному мероприятию.

## What Changes

- В рабочем месте организатора появляется действие **«Буклет ситуаций»** по мероприятию, которое формирует **PDF-файл** на сервере (скачивание/печать).
- Буклет имеет **две оси вариантов** (переключатели перед генерацией):
  - **Состав**: «все ситуации из банка» или «только ситуации мероприятия»;
  - **Инструкции**: «с инструкцией для судей» или «без».
- **«Только ситуации мероприятия»** = уникальные `duels.situation_id` слотов сетки этого мероприятия (в порядке слотов).
- **Инструкция для судей** — общий методический текст на **отдельной странице** буклета (в начале/конце), единый для мероприятия.
- **Обложка** содержит **логотип мероприятия**, дату и заголовок.
- Логотип мероприятия хранится в **новом поле карточки мероприятия** (загрузка файла организатором); для типов **«купала»** и **«новогоднее»** логотип **проинициализирован** заранее (значение по умолчанию).
- **Структура буклета**: секции по типу поединка (Классические / Экспресс / Парные), внутри — карточки ситуаций: заголовок «Ситуация N (оригинальный номер)», текст ситуации, блок «Роли и интересы» из `roles_json`.
- Генерация доступна только организатору мероприятия и не изменяет данные ситуаций.

## Capabilities

### New Capabilities
- `org-situation-booklet`: генерация серверного PDF-буклета ситуаций по мероприятию — выбор состава (все / только мероприятие) и наличия инструкции судьям, обложка с логотипом мероприятия, секции по типам поединков и карточки ситуаций из банка.

## Impact

- [portal/inc/org_events.php](../../../portal/inc/org_events.php) — новый обработчик генерации буклета, кнопка/секция на карточке мероприятия, загрузка логотипа в карточку.
- Новый модуль `portal/inc/org_booklet.php` — сборка HTML/структуры буклета и рендер PDF.
- PDF-библиотека размещается в `portal/vendor/` (по FTP, **без composer**); размер и совместимость с shared-hosting учитываются.
- БД: новое поле `events.logo_path` (миграция) — путь к логотипу мероприятия.
- Ассеты: два предустановленных логотипа (для «купала» и «новогоднее») и текст общей инструкции судьям.
- Данные: чтение `situations` (`code`, `num`, `duel_type`, `description`, `roles_json`), `duels` (`event_id`, `situation_id`, `sort_order`).
- Деплой портала по FTP ([scripts/deploy_portal.ps1](../../../scripts/deploy_portal.ps1)).
- Не затрагивает таймер, автоназначение судей, протокол и данные поединков.

## Non-goals

- Не генерируем DOCX/RTF — только PDF.
- Не редактируем сами ситуации из буклета (текст берётся из банка как есть).
- Не даём ручной выбор ситуаций в буклете — для состава «мероприятие» источник только сетка поединков.
- Не меняем логику таймера, судей, протокола и генерации пар.
