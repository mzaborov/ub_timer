## Purpose

Даёт организатору веб-форму для разметки записи онлайна по поединкам, точной синхронизации таймкодов и нарезки видео на фрагменты, которые сразу привязываются к поединкам в портале.

## ADDED Requirements

### Requirement: Доступ к форме нарезки

Форма MUST быть доступна только в org-разделе портала и только после входа организатора. Локальный Python-сервис MUST принимать запросы только с `127.0.0.1` и по одноразовому токену, выданному порталом на текущую сессию.

#### Scenario: Организатор открывает форму
- **WHEN** организатор открывает раздел «Нарезка видео»
- **THEN** портал показывает выбор мероприятия, плеер и таймлайн с поединками

#### Scenario: Нет доступа
- **WHEN** пользователь без org-сессии открывает форму или обращается к API сервиса
- **THEN** портал перенаправляет на вход, а сервис отвечает 401/403

### Requirement: Загрузка исходной записи

Форма MUST позволять выбрать локальный видеофайл на машине пользователя или указать ссылку на файл Google Drive. Для локального файла сервис MUST получать путь и метаданные (длительность, разрешение, частоту кадров, наличие ключевых кадров) без загрузки файла на портал.

#### Scenario: Локальный файл
- **WHEN** организатор выбирает файл на диске
- **THEN** сервис возвращает метаданные и открывает файл в плеере формы

#### Scenario: Ссылка на Drive
- **WHEN** организатор вставляет ссылку на файл Drive
- **THEN** сервис получает метаданные через Drive API и открывает поток для предпросмотра

### Requirement: Автоматическая разметка поединков

Форма MUST формировать предварительные границы поединков по данным мероприятия: порядок поединков, игроки и абсолютное время старта из протокола. Границы MUST уточняться детекцией смены сцены и ключевых кадров; при отсутствии данных протокола допускается разметка только по сцене.

#### Scenario: Данные протокола есть
- **WHEN** для мероприятия загружены поединки и события протокола со временем
- **THEN** таймлайн показывает маркеры начала и конца для каждого поединка с ФИО игроков

#### Scenario: Данных протокола нет
- **WHEN** у мероприятия нет времени старта поединков
- **THEN** форма предлагает границы по смене сцены и помечает их как требующие проверки

### Requirement: Ручная корректировка таймкодов

Организатор MUST иметь возможность сдвинуть всю разметку целиком для синхронизации со стартом записи и отдельно изменить начало и конец любого поединка. Изменения MUST сохраняться в черновике разметки до запуска нарезки.

#### Scenario: Глобальный сдвиг
- **WHEN** организатор меняет общий сдвиг на N секунд
- **THEN** все маркеры сдвигаются на N секунд, индивидуальные правки сохраняются

#### Scenario: Правка одного поединка
- **WHEN** организатор двигает начало или конец поединка
- **THEN** маркеры соседних поединков не меняются, а границы не пересекаются

### Requirement: Превью кадров

Для каждого поединка форма MUST показывать стартовый и финальный кадры и позволять перейти к любому маркеру на таймлайне.

#### Scenario: Проверка границ
- **WHEN** организатор выбирает поединок
- **THEN** форма показывает кадры на его начале и конце и позволяет перейти к следующему или предыдущему маркеру

### Requirement: Нарезка и имена файлов

Сервис MUST резать запись по утверждённым границам через ffmpeg без перекодирования звука и с настраиваемыми параметрами видео (кодек, CRF/битрейт, пресет). Имя каждого файла MUST следовать шаблону `{дата}_{мероприятие}_{номер}_{игрок1}_vs_{игрок2}.mp4` с заменой недопустимых символов.

#### Scenario: Успешная нарезка
- **WHEN** организатор запускает нарезку
- **THEN** сервис создаёт по файлу на каждый поединок с корректными именами и сообщает прогресс

#### Scenario: Нет ffmpeg
- **WHEN** ffmpeg не найден в системе
- **THEN** форма показывает понятную ошибку и не начинает нарезку

### Requirement: Публикация фрагментов

После нарезки сервис MUST загружать фрагменты в выбранную папку Google Drive и создавать записи в `videos` с `event_id`, `duel_id`, `video_type='Поединок'`, названием и ссылкой. Повторная публикация MUST предлагать обновить существующую запись, а не создавать дубль.

#### Scenario: Публикация
- **WHEN** нарезка завершена и организатор подтверждает загрузку
- **THEN** фрагменты появляются в Drive, а в портале у поединков появляются ссылки на видео

#### Scenario: Повторная публикация
- **WHEN** для поединка уже есть запись `videos`
- **THEN** форма предлагает заменить ссылку или пропустить этот поединок

### Requirement: Ошибки и прерывание

Сервис MUST корректно обрабатывать недоступный файл, нехватку места, обрыв загрузки и отмену пользователем. Частично созданные файлы и записи MUST не публиковаться как успешные.

#### Scenario: Отмена нарезки
- **WHEN** организатор отменяет операцию
- **THEN** сервис останавливает ffmpeg и удаляет незавершённые фрагменты

#### Scenario: Ошибка загрузки в Drive
- **WHEN** загрузка фрагмента завершилась ошибкой
- **THEN** форма показывает, какие поединки опубликованы, а какие нет, и позволяет повторить только неудачные
